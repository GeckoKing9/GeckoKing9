# GeckoKing9

Security engineer and full-stack developer in Montréal. I break mobile apps and web platforms, and I build the tooling and products behind them.

Offensive security (mobile and web application testing, vulnerability research) with a developer's background: a React/Next.js and Go platform grown to 5,000+ users. Trilingual (FR / EN / ES).

### Security work

- **[ios-app-security-toolkit](https://github.com/GeckoKing9/ios-app-security-toolkit)** is one command-line driver over the iOS application security assessment lifecycle: recon, cross-runtime reverse engineering, dynamic instrumentation, and findings mapped to the OWASP MASVS standard. Pure-Python Mach-O hardening checks, no macOS required, with unit tests and CI.
- **[homelab-security-lab](https://github.com/GeckoKing9/homelab-security-lab)** is a self-hosted security lab on a Raspberry Pi: attack-surface monitoring, hardened DNS, private mesh networking, and a Wi-Fi monitoring pipeline. Sanitized; the engineering, not the live config.

### Products and tools

- **[dwell](https://github.com/GeckoKing9/dwell)** is a Chrome extension that measures website screen time locally, with short-form feed blockers. CI and a full test suite.
- **[insta-safari](https://github.com/GeckoKing9/insta-safari)** is a Safari userscript that strips Instagram's attention traps, with a headless test harness for on-device verification.
- **[claude-code-copy-button](https://github.com/GeckoKing9/claude-code-copy-button)** adds a copy link to code blocks in Claude Code (WSL, Windows Terminal, Linux).
- **[beat-analyser](https://github.com/GeckoKing9/beat-analyser)** checks whether the cuts in a video edit land on the beat.
